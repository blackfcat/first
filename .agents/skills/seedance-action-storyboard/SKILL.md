# Seedance 打戏分镜

1. 提取人物、参考素材、场景、画幅和时长。缺省用中文、9:16、10 秒，用户指定时覆盖。为每份已提供的素材标明角色外观、场景或运镜用途。素材缺失时用文字描述。
2. 画出银幕空间。记录人物初始左右、动作趋向、固定地标和摄影机一侧。需要反打时，用正面中性机位或可见的跨轴移动交代新方位。
3. 把动作写成「观众先看见什么、随后什么发生改变、最后停在哪」。优先写走位、错身、衣袖和环境反应，用景别、遮挡和音画剪辑呈现虚构交锋。每段安排一个主动作和一个主要摄影机动作。
4. 前三秒用可读的空间关系和一次清晰的动作变化建立钩子。快切前先让观众看清人物位置。需要冲击帧时，说明剪辑落点、形状和延续方向。
5. 每镜输出「时间码 | 景别与机位 | 起幅 | 可见动作与声音 | 落幅 | 切点」。接镜时继承人物方位、视线和仍在运动的元素。最后附可复制的中文提示词，按时间段写成画面描述。

## 走查样例

输入「10 秒竖屏，白衣和灰衣两人在雨巷上演无接触奇幻交锋，白衣最后发现灯笼熄了。」

| 时间 | 机位 | 起幅 → 动作 → 落幅及切点 |
|---|---|---|
| 0–3 秒 | 同侧中全景，轻推 | 白衣在左，灰衣在右，巷尾红灯笼亮。两人的衣摆被同一阵侧风推向画面右侧，白衣转头追随灯笼的摆动。切在白衣转头途中。 |
| 3–6 秒 | 同侧中景，短横移 | 承接转头，灰衣向画面右侧退到檐影，白衣留在左侧。摄影机横移时，前景柱边从右遮入。切在柱边遮挡峰值。 |
| 6–10 秒 | 同侧过肩近景，缓推 | 柱边移出，白衣肩仍在左前景，灰衣留在右侧檐影。巷尾红灯熄灭，雨声先前的空间位置不变，白衣抬眼停住。 |

检查样例中的时间是否连续、左右关系是否稳定、切点是否可接，以及前三秒能否读清局面。
