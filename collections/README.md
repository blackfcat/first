# 短剧与网文创作项目收藏

| 项目 | 用途 | 收藏版本 |
| --- | --- | --- |
| [Drama Skills](drama-skills) | 拆短剧与漫剧、原著分析、立项、分集大纲、分集剧本和审稿 | [查看上游版本](https://github.com/zenstory-ai/drama-skills/tree/9055a84f6563c04fa43b599e1dbd3a216884fdde) |
| [Oh Story](oh-story-claudecode) | 扫榜选题、拆网文、原创小说、大纲与正文、长篇状态追踪、去 AI 味 | [查看上游版本](https://github.com/zenstory-ai/oh-story-claudecode/tree/dbc7d59d21843cf3b5a19f8049b30739a7303148) |

两个项目分别固定在收藏时的上游提交。要把收藏项目的源码下载到已克隆的仓库，在仓库根目录运行：

```bash
git submodule update --init -- collections/drama-skills collections/oh-story-claudecode
```

各项目的使用方式、依赖和许可证见各自的 README 和授权文件。
